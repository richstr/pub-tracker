# Changelog

Notable changes to each test build are recorded here.

## v0.1.0-test.2 - 2026-11-04

- Add a challenge radius editor with a fixed centre, updated map circle and OSM preview.
- Show the number of pubs and bars that will be added or removed before applying a radius change.
- Add newly discovered places when the change is applied; remove out-of-radius links without deleting pub or visit history.
- Add challenge search by pub name or street.
- Add an included-in-challenge switch on pub details.
- Default new challenges to include both pubs and bars.
- Add map zoom controls.

## v0.1.0-test.1 - 2026-11-04

- Initial personal-use build with multiple challenges, OSM place discovery, map and list views, manual pub management, and check-ins with optional notes, drinks, ratings and photos.
